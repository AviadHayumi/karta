# how the fake operator produces utilization (read from ~/workspace/fake-gpu-operator, main at a3725bf):
#   status-updater watches gpu pods; on add it allocates a gpu in the per-node topology ConfigMap and stores
#   podGpuUsageStatus[pod.UID] = calculateUsage(pod)   (handlers/pod/dedicated_gpu_pod_handler.go:44)
#   on EVERY pod update it recomputes calculateUsage(pod)  (dedicated_gpu_pod_handler.go:69-75) -> annotation changes land live
#   calculateUsage: not Running -> 0 ; name prefix runai-idle-gpu- -> 0 ; annotation run.ai/simulated-gpu-utilization
#   "N" or "N-M" -> Range{N,M} (gpu_usage_calculator.go:51-60, 83-104) ; else podgroup type ; default 100
#   status-exporter (DaemonSet nvidia-dcgm-exporter) republishes every 10s: DCGM_FI_DEV_GPU_UTIL{gpu,UUID,device,modelName,
#   Hostname,container,namespace,pod} = sum of Range.Random() over pods on that gpu, capped 100 (export/metrics/exporter.go:67-90,
#   topology/podGpuUsageStatusMap.go:14-24) ; Random() returns Min when Min == Max (topology/range.go:7-13)
